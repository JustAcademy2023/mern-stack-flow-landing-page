# MERN Metro: Understanding MERN Stack Application Flow From Frontend to Backend

An interactive, single page landing site that explains how one request travels through the MERN stack. Instead of a dry diagram, you ride a subway line from the React screen to the Express router, through middleware and a controller, into MongoDB and all the way home again.

## What you can do on the page

Type a task such as "Buy milk", press Send request and watch a ticket move along the metro map. Each station lights up, a journey log explains what happened, the React screen updates and a MongoDB document appears in the tasks collection. Tap any station name for a plain language explanation, flip the four technology cards to see what each letter of MERN does, and open the guides and courses below the map.

## Features

A hand drawn style subway map built with inline SVG, a request simulator written in plain JavaScript, flip cards for React, Node, Express and MongoDB, scroll reveal animations, a sticky header, a friendly footer, keyboard friendly buttons and support for reduced motion preferences. The layout is fully responsive and works from small phones to wide desktops. There are no frameworks, no build step and no dependencies.

## Colour palette

Teal, yellow, pink, red, brown and magenta on a warm cream background.

## Run it locally

Download or clone the repository and open `index.html` in any modern browser. That is all.

## Publish it with GitHub Pages

Push the files to a repository, open Settings, choose Pages, select the main branch and the root folder, then save. Your landing page will be live at your GitHub Pages address within a minute or two.

## Project structure

`index.html` holds the markup, styles and script in a single file.
`README.md` is this document.

## Customise

Change the colours in the `:root` block at the top of the stylesheet, edit the stations in the `S` array inside the script, or add more cards in the grid sections.
